隱私權政策 / Privacy Policy

適用對象：NEWPOWER backup（公司內部備份工具）。 / Applies to: NEWPOWER backup (internal backup tool).

存取哪些資料 / Data accessed

本工具只使用 Google Drive 的 drive.file 權限，只能建立、讀取、刪除它自己上傳的備份檔案，無法看到雲端硬碟中的其他檔案。

The tool uses only the Google Drive drive.file scope. It can create, read and delete only the backup files it uploaded itself, and cannot see any other files in Google Drive.

如何使用 / How data is used

備份檔在上傳前已加密，只用於公司自己的資料還原。本工具不收集個人資料，不使用追蹤或廣告，也不會把任何資料分享、出售或傳送給第三方。

Backups are encrypted before upload and are used only to restore our own data. The tool collects no personal data, uses no tracking or advertising, and never shares, sells or transfers any data to third parties.

保存與刪除 / Retention and deletion

備份檔保留約 30 天後自動刪除。可隨時在 Google 帳戶的「第三方應用程式」設定中撤銷授權。

Backups are kept for about 30 days and then deleted automatically. Access can be revoked at any time in the Google Account third-party apps settings.

Google API 資料的使用遵守 Google API Services User Data Policy（包括 Limited Use 規定）。 / Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
