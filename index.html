NEWPOWER backup

NEWPOWER backup 是一個內部使用的備份工具：每天把公司 ERP 系統的資料庫備份檔（已加密）上傳到公司自己的 Google 雲端硬碟，作為異地備份。

NEWPOWER backup is an internal tool that uploads encrypted database backups of our own ERP system to our own Google Drive as an off-site backup.

  • 只供公司內部使用，不對外提供服務。 / For internal use only; not offered to the public.
  • 只要求 Google Drive 的 drive.file 權限：只能存取它自己上傳的檔案。 / Requests only the drive.file scope: it can access only files it created.
